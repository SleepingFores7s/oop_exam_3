🧩 15 Puzzle Game – Java Swing Edition
A classic sliding puzzle built with Java Swing, featuring a randomized 4×4 grid, responsive UI, and a celebratory win screen.

🎮 Features
- 	4×4 Sliding Puzzle: Rearrange tiles numbered 1–15 into order by sliding them into the empty space.
- 	Randomized Start: Each game begins with a freshly shuffled board.
- 	Win Detection: Automatically detects when the puzzle is solved and displays a win message.
- 	Clean UI: Subtle color palette, centered layout, and responsive button interactions.
- 	Reset Functionality: Start a new game at any time with the “New Game” button.
